# ⚡ RetroNFC — Colecionáveis Retrô & Tecnologia NFC

Plataforma web oficial para apresentação e comercialização de **chaveiros colecionáveis em impressão 3D de alta definição** com chips de aproximação **NFC integrados**.

Uma experiência nostálgica completa que conecta o produto físico ao ambiente digital instantâneo sem necessidade de instalar aplicativos.

---

## 🎮 Principais Recursos

- **Vitrine E-Commerce Completa:** Catálogo dinâmico com mais de 50 clássicos retrô divididos por consoles e gêneros.
- **Simulador Interativo:** Demonstração visual em tempo real de como funciona a aproximação NFC no smartphone.
- **Checkout Direto via WhatsApp:** Geração automática de pedidos personalizados com escolha de modelo, cor de carcaça e formato.
- **Calculadora B2B para Lojistas:** Ferramenta interativa de cálculo de margem e projeção de lucro para pedidos no atacado com expositor de brinde.
- **Visual Cyber-Retro Premium:** Interface com dark mode, efeitos de glassmorphism, animações a 60 FPS e scanlines de TV CRT.
- **PWA (Progressive Web App):** Compatível com instalação direta na tela inicial de smartphones Android e iOS.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5 Semântico, CSS3 Moderno (Variáveis Customizadas, Glassmorphism, Flexbox/Grid)
- **Engine:** Vanilla JavaScript (ES6+)
- **Áudio:** Web Audio API para efeitos sonoros sintetizados estilo 16-bit
- **Animações:** Canvas 2D acelerado por hardware para prévias retrô

## 💻 Como Executar Localmente

```bash
# 1. Clone o repositório
git clone https://github.com/Maclaude3/retronfc.git

# 2. Acesse a pasta do projeto
cd retronfc

# 3. Inicie um servidor local simples
# Com Python 3:
python -m http.server 8000

# Ou com Node.js (npx):
npx serve .
```

Abra o navegador em `http://localhost:8000` para visualizar a loja.
